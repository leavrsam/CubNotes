# Motif

> **The Infinite Spatial Canvas for Spoken Thought.**  
> Powered by **Gemini 3.8 Flash** for speaker-diarized meeting transcription, executive summaries, orthogonal flowchart generation, and spatial whiteboarding.

---

## Overview

Motif replaces the rigid, vertical document with a boundless, two-dimensional spatial workspace. Spoken conversations and brainstorms are captured mid-air, synthesized by Gemini 3.8 Flash, and organized into an interconnected network of vector nodes, flowcharts, and rich notes.

* **Infinite Spatial Canvas**: Pan, zoom, minimap, pressure-sensitive handwriting, rich text TipTap blocks, and media nodes.
* **Acoustic Intelligence**: Real-time speech recognition, long-meeting audio recording, and automated speaker-diarized transcription.
* **Generative Flowcharts**: Instant translation of disorganized meeting dialogue into orthogonal Manhattan-routed flowcharts.
* **Multi-Platform**: Web (Next.js), Desktop (Tauri), and Mobile (Capacitor for Android/iOS with background audio recording).
